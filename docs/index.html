01 / Sketchbook Highlights

为什么选择这套模板

把繁琐的字号、20 磅固定行距、双面页眉与多套题名页全部封装进 cugthesis.cls。

完整 16 部分顺序覆盖

封面、中英文题名页、原创性声明、导师承诺书、使用授权书、作者简介、答辩委员会名单、中英文摘要、目录、图表清单、正文、参考文献、致谢与附录一应俱全。

6 类学位一键切换

内置学术型硕士、博士、全日制专硕、非全日制专硕、同等学力硕博，自动切换“专业学位类别”、企业导师、英文题名页模板与奇数页页眉。

逐项对齐 2025 版规范

A4 四周 3 cm 页边距、正文宋体/Times New Roman 小四固定行距 20 磅、一级节标题黑体四号居中、正文奇偶页眉外侧页码，精确对照附件 1–11。

GB/T 7714 双引文体制

基于 gbt7714 原生支持顺序编码制（上标 [1] 自动压缩）与著者-出版年制，示范期刊、图书、会议、学位论文、标准与专利条目。

跨平台零配置字体

fontset=auto 自动识别 Windows（宋体/黑体/仿宋）、macOS（Songti SC/Heiti SC/仿宋_GB2312）与 Linux / Overleaf 内置 Fandol 字体，告别缺字报错。

盲审、书脊与印刷模式

一行选项即可切换盲审遮罩（blind=true）、关闭自制封面（cover=false）、双面印刷补白（print=true）与仿宋竖排书脊（spine=true）。

04 / Field Notes

      
编译与新增章节指南

      
支持本地命令行、VS Code 与 Overleaf，新增一章只需两步。

    


    

      

        

          
          
          
        


        

          

            
Terminal（macOS / Linux / Windows）

            
# 1. 克隆模板并进入目录
git clone https://github.com/zhanlutuzi/cug-thesis-latex.git
cd cug-thesis-latex

# 2. 一键编译（已配置 latexmkrc，自动执行 XeLaTeX + BibTeX）
latexmk -xelatex main.tex

# 或直接运行 make / 清理中间文件
make
make clean

          

        


        

          

            
VS Code + LaTeX Workshop

            
1. 安装扩展：LaTeX Workshop
2. 用 VS Code 打开模板文件夹，打开 main.tex
3. 按 Cmd+Option+B (macOS) 或 Ctrl+Alt+B (Windows)
   根目录 latexmkrc 会自动启用 XeLaTeX + BibTeX 完整编译
4. 按 Cmd+Option+V / Ctrl+Alt+V 实时分屏预览 PDF

          

        


        

          

            
Overleaf 在线编辑

            
1. 下载仓库 ZIP 压缩包
2. 在 Overleaf 点击 New Project -> Upload Project 上传 ZIP
3. 点击左上角 Menu -> Compiler，切换为 XeLaTeX
4. 点击 Recompile 即可在线生成 main.pdf（自动使用 Fandol 字体）

          

        

      


      

        

          
新增一章（两步完成，编号与目录自动更新）

          
% 第 1 步：在 chapters/ 下新建 chap05.tex
% !TeX root = ../main.tex
\chapter{你的新章节标题}
\section{第一节标题}
正文内容……

% 第 2 步：在 main.tex 的 \cugmainmatter 下加入一行 \include
\cugmainmatter
\include{chapters/chap01}
\include{chapters/chap02}
\include{chapters/chap03}
\include{chapters/chap05}  % 自动编为“第四章”
\include{chapters/chap04}  % 原结论自动顺延为“第五章”

        

      

    

  


  

    

      
05 / Specification Ledger

      
2025 年 5 月写作规范核心参数对照

      
全部数值均取自仓库内 学校规范/ 目录中的官方正文与附件 1–11。

    


    

      

        
          

            纸张与页边距（3.1）
            A4（210 × 297 mm），上下左右均为 3 cm，页眉 2.5 cm，页脚 2.0 cm，装订线 0 cm。
          

          

            页眉与页码（2.4 / 附件 10）
            五号（10.5 磅）宋体带下划线；奇数页居中“中国地质大学□学位论文”，页码居右上角；偶数页居中“作者姓名：论文题目”，页码居左上角；摘要/目录用大写罗马数字 I, II...，正文自第一章起用阿拉伯数字 1, 2...。
          

          

            各级标题（2.3 / 表 3.8）
            章标题（第一章 ×××）黑体三号加粗居中；一级节标题（1.1 ×××）黑体四号加粗居中；二级节标题（1.1.1 ×××）黑体小四居左；序号与题名间隔 1 个汉字符。
          

          

            正文与摘要（3.6 / 3.8）
            宋体小四（12 磅），英文 Times New Roman 小四，两端对齐，首行缩进 2 汉字符，固定值行距 20 磅，段前段后 0 磅。
          

          

            图、表与公式（2.5 / 表 3.8）
            图下表上，五号宋体居中单倍行距，序号与题名空 1 汉字符；推荐三线表，跨页续表重复表头并标“（续）”；公式编号 (2.1) 五号 Times New Roman 右对齐。
          

          

            参考文献（2.6 / 3.9 / 附件 11）
            遵循 GB/T 7714，支持顺序编码制与著者-出版年制；宋体 / Times New Roman 小四，固定行距 20 磅。
